# Fathur School Hub — Editorial Theme v5.3

Visual direction is adapted from the supplied General Intelligence Company style reference while keeping the School Hub information architecture and all existing routes/functions.

## Design language
- Warm parchment canvas: #fefffc
- White paper cards: #ffffff
- Linen inputs: #f9faf7
- Graphite/charcoal text
- Hairline green-gray borders: #dee2de
- Signal Blue #41a1cf for outlined actions
- Cerulean #0081c0 only for rare atmospheric emphasis
- Serif display headlines with Georgia as a safe local substitute
- Sans-serif UI for controls and metadata
- Sidebar retained, but converted from dark-first chrome to editorial paper navigation
- Header converted into a light frosted pill
- Existing dark mode remains available and functional

## Functional preservation
No route is intentionally removed. The theme layer is additive and scoped to `.editorial-theme` and light mode.
