# Fathur School Hub v5.0 — System-Wide Upgrade

This release preserves existing routes and feature contracts while adding an additive motion/interaction layer.

## Upgrade highlights
- Page transition animation on route content.
- Staggered section entrance animations.
- Consistent hover/press micro-interactions for buttons and links.
- Active navigation indicator animation.
- Skeleton shimmer utility.
- Live status glow utility.
- Modal/toast entrance utilities.
- Progress flow animation utility.
- Icon bounce utility.
- Full reduced-motion compatibility.
- Package version bumped to 5.0.0.

No existing route has been removed.
