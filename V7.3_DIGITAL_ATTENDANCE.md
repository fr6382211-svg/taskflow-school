# Fathur SchoolHub V7.3 — Digital Attendance 2.0

## Tujuan
Attendance baru menjadi modul verifikasi terintegrasi dengan Supabase, workspace, schedule/location context, dan Admin Center.

## Metode check-in
- **Tap Kartu Absen Digital**: user memilih sesi aktif lalu melakukan satu tap. Browser meminta GPS high accuracy; server memverifikasi sesi, waktu, workspace, dan geofence.
- **Scan QR Admin**: Admin membuka session dan QR otomatis berubah menggunakan nonce 45 detik. Student scan QR lalu server memverifikasi nonce + GPS + waktu.

## Lokasi wajib
- Sekolah: radius 400 m.
- Tempat Les: radius 200 m.
- Koordinat hanya digunakan sebagai master geofence server-side. Attendance log menyimpan lokasi ID, jarak, dan akurasi; koordinat GPS mentah tidak disimpan.

## Anti-replay
- QR tidak statis.
- Nonce disimpan server-side dan diputar otomatis.
- Satu user hanya dapat check-in sekali per session (`session_id,user_id` unique).
- Server timestamp menentukan on-time/late.

## Admin
`/admin/attendance`
- create session
- pilih workspace
- pilih School / Tutoring
- atur waktu & late threshold
- tampilkan QR
- rotate QR manual
- live roster via Supabase Realtime
- finalize session → pengguna aktif yang tidak check-in menjadi absent
- permission override

## Privacy
Location permission harus diberikan oleh browser. Tidak ada background GPS baru yang diaktifkan oleh modul ini. Browser location spoofing tidak dapat dijamin 100% oleh web platform; sistem meminimalkan replay dan mencatat evidence server-side.
